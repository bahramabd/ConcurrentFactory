This Java project demonstrates the basic and intermediate concepts of concurrent programming using Java. Done in 2023.
It was developed in IntelliJ IDEA and includes examples of threads, synchronization, asynchronous tasks, monitors, and shared resource management.

The goal of this project is to understand how multiple threads can run at the same time, how shared data can be protected, and how Java provides tools to manage concurrent execution safely.

## Topics Covered

- Creating and running threads
- Using the `Runnable` interface
- Using the `Thread` class
- Synchronous execution
- Asynchronous execution
- Race conditions
- Synchronization with `synchronized`
- Object monitors
- Thread communication using `wait()` and `notify()`
- Thread-safe access to shared resources
- Basic concurrency problems
- ExecutorService for managing threads
- Future and CompletableFuture for async programming
